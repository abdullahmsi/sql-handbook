Part 1 • Chapters 1 – 5

Database Foundations & Schema Design

▼

1. SQL & Database Fundamentals

Database, DBMS, RDBMS (Codd's 12 rules), SQL vs MySQL vs PostgreSQL vs SQL Server vs Oracle, Table, Row/Tuple, Column, Schema, Keys (Primary, Foreign, Candidate, Super, Alternate, Composite, Natural, Surrogate), NULL, Constraints & Relationships.

2. SQL Data Types

Numeric (INT, BIGINT, SMALLINT, TINYINT, DECIMAL, NUMERIC, FLOAT, DOUBLE), String (CHAR, VARCHAR, TEXT, MEDIUMTEXT, LONGTEXT), Date & Time (DATE, TIME, DATETIME, TIMESTAMP, YEAR), JSON, ENUM, SET, BLOB, Precision & Scale.

3. Database & Table Creation (DDL)

CREATE DATABASE, CREATE TABLE, ALTER TABLE (ADD, MODIFY, CHANGE, DROP, RENAME column), DROP TABLE, TRUNCATE TABLE, and RENAME TABLE operations.

4. Constraints & Referential Integrity

PRIMARY KEY, FOREIGN KEY, UNIQUE, NOT NULL, DEFAULT, CHECK, AUTO_INCREMENT, Column vs Table-level constraints, Named constraints, and ON DELETE / ON UPDATE actions (CASCADE, SET NULL, RESTRICT, NO ACTION).

5. CRUD Operations (DML)

Single-row & Multi-row INSERT INTO, Insert using SELECT, UPDATE, DELETE, and critical differences between DELETE vs TRUNCATE vs DROP.

Part 2 • Chapters 6 – 15

Querying, Filtering & Built-In Functions

▼

6. SELECT Statement — Deep Level

SELECT, FROM, WHERE, DISTINCT, AS (Column & Table aliases), ORDER BY (ASC/DESC, multi-column sorting), and LIMIT + OFFSET for web pagination.

7. WHERE Clause & Pattern Matching

Comparison operators, Logical operators (AND, OR, NOT), BETWEEN, IN, NOT IN, LIKE, NOT LIKE, IS NULL, IS NOT NULL, and Wildcards (% and _).

8. SQL Operators

Arithmetic (+, -, *, /, %), Comparison (=, !=, <>, >, <, >=, <=), Logical, and Bitwise Operators (&, |, ^, <<, >>).

9. String Functions

CONCAT(), CONCAT_WS(), LENGTH(), CHAR_LENGTH(), LOWER(), UPPER(), TRIM(), LTRIM(), RTRIM(), SUBSTRING(), LEFT(), RIGHT(), REPLACE(), REVERSE(), LOCATE(), POSITION().

10. Numeric Functions

ABS(), CEIL() / CEILING(), FLOOR(), ROUND(), TRUNCATE(), MOD(), POWER(), SQRT(), and RAND().

11. Date & Time Functions

NOW(), CURRENT_DATE(), CURRENT_TIME(), YEAR(), MONTH(), DAY(), DATE_ADD(), DATE_SUB(), DATEDIFF(), TIMEDIFF(), DATE_FORMAT(), DAYNAME(), MONTHNAME(), LAST_DAY().

12. NULL Handling

NULL vs 0 vs Empty String (''), IS NULL, IS NOT NULL, COALESCE(), IFNULL(), and NULLIF() to prevent division-by-zero errors.

13. Aggregate Functions

COUNT(), SUM(), AVG(), MIN(), MAX(), Scalar vs Aggregate functions, and COUNT(*) vs COUNT(column) vs COUNT(DISTINCT column).

14. GROUP BY Clause

Grouping summary rows with aggregates, department-wise employee counts, city-wise customer reports, and monthly sales summaries.

15. HAVING Clause & Logical Query Execution Order

WHERE vs HAVING filtering mechanics and the complete SQL execution order: FROM → WHERE → GROUP BY → HAVING → SELECT → DISTINCT → ORDER BY → LIMIT.

▼

Slow query log analysis, dropping unused indexes, connection pooling, reducing lock contention, and RAM buffer hit optimization.

Table Partitioning (Range, Hash, List), Horizontal Sharding, Master-Replica Replication, Vertical vs Horizontal Scaling, CAP Theorem & Eventual Consistency.

43. JSON in SQL

Native JSON & JSONB types, JSON_EXTRACT(), -> and ->> path operators, indexing virtual generated columns, and Relational vs JSON modeling.

Inverted FULLTEXT indexes, MATCH() AGAINST(), relevance ranking scores, Natural Language mode, and Boolean mode (+, -, *).
