Part 01 • Chapters 01 to 05

Database Foundations and Schema Design

Chapter 01: SQL and Database Fundamentals

Database, DBMS, RDBMS (Codd's 12 rules), SQL vs MySQL vs PostgreSQL vs SQL Server vs Oracle, Table, Tuple, Column, Schema, Keys (Primary, Foreign, Candidate, Super, Alternate, Composite, Natural, Surrogate), and Table Relationships.

Chapter 02: SQL Data Types

Numeric (TINYINT, SMALLINT, INT, BIGINT, DECIMAL, NUMERIC, FLOAT, DOUBLE), String and Text (CHAR, VARCHAR, TEXT, MEDIUMTEXT, LONGTEXT), Date and Time (DATE, TIME, DATETIME, TIMESTAMP, YEAR), BOOLEAN, JSON, ENUM, SET, and BLOB.

Chapter 03: Database and Table Creation (DDL)

CREATE DATABASE, CREATE TABLE, copying tables (LIKE vs AS SELECT), ALTER TABLE (ADD, MODIFY, CHANGE, RENAME, DROP), DROP TABLE, and DROP vs TRUNCATE vs DELETE comparison.

Chapter 04: Constraints and Referential Integrity

NOT NULL, UNIQUE, PRIMARY KEY, FOREIGN KEY with ON DELETE and ON UPDATE cascades (CASCADE, SET NULL, RESTRICT), CHECK, DEFAULT, INDEX, and AUTO_INCREMENT internals.

Chapter 05: CRUD Operations (DML)

Single and multi row INSERT INTO, INSERT INTO SELECT, UPDATE with expressions, DELETE, MERGE and UPSERT (ON DUPLICATE KEY UPDATE), CALL, LOCK TABLES, and DDL vs DML comparison.

Part 02 • Chapters 06 to 15

Querying, Filtering and Built In Functions

Chapter 06: SELECT Statement (Deep Level)

SELECT and FROM, specific columns vs SELECT *, WHERE filtering, DISTINCT, Column and Table Aliases (AS), ORDER BY (ASC, DESC, multi column sorting), and LIMIT with OFFSET pagination.

Chapter 07: WHERE Clause and Pattern Matching

Comparison conditions, Logical operators (AND, OR, NOT), BETWEEN, IN, NOT IN, LIKE, NOT LIKE, IS NULL, IS NOT NULL, Wildcards (% and _), bracket wildcards, and ESCAPE clauses.

Chapter 08: SQL Operators

Arithmetic, Comparison (including null safe <=>), Logical (EXISTS, ALL, ANY, SOME), Bitwise operators (&, |, ^, ~, <<, >>), and complete Operator Precedence order.

Chapter 09: String Functions

CONCAT(), CONCAT_WS(), LENGTH(), CHAR_LENGTH(), LOWER(), UPPER(), TRIM(), LTRIM(), RTRIM(), SUBSTRING(), LEFT(), RIGHT(), REPLACE(), REVERSE(), LOCATE(), and POSITION().

Chapter 10: Numeric Functions

ABS(), CEIL() and CEILING(), FLOOR(), ROUND() vs TRUNCATE(), MOD(), POWER() and POW(), SQRT(), and RAND() for random sampling.

Chapter 11: Date and Time Functions

NOW(), CURDATE(), CURTIME(), YEAR(), MONTH(), DAY(), DATE_ADD(), DATE_SUB(), DATEDIFF(), TIMESTAMPDIFF(), TIMEDIFF(), DATE_FORMAT(), STR_TO_DATE(), and index safe date filtering.

Chapter 12: NULL Handling

NULL vs 0 vs Empty String, IS NULL, IS NOT NULL, Null safe operator (<=>), IFNULL(), COALESCE(), and NULLIF() to prevent division by zero errors.

Chapter 13: Aggregate Functions

Scalar vs Aggregate functions, COUNT(), SUM(), AVG(), MIN(), MAX(), and critical differences between COUNT(*), COUNT(column), and COUNT(DISTINCT column).

Chapter 14: GROUP BY Clause

Grouping summary rows for department wise counts, city wise customer distributions, category stock summaries, and monthly sales revenue.

Chapter 15: HAVING Clause and Logical Execution Order

WHERE vs HAVING filtering mechanics and the complete 8 step SQL logical execution order from FROM and JOIN through LIMIT and OFFSET.

Part 03 • Chapters 16 to 23

Joins, Subqueries and Advanced Analytics

Chapter 16: Joins (Inner, Left, Right, Full, Cross, Self)

Visual Venn diagrams for INNER, LEFT, RIGHT, FULL OUTER, CROSS, and SELF JOIN, physical join algorithms (Nested Loop, Hash, Sort Merge), ON vs WHERE filters, and Anti Joins.

Chapter 17: Subqueries (Single, Multi Row, Correlated)

Single row, Multiple row, Multiple column tuple comparisons, Correlated subqueries, Nested subqueries, and IN, NOT IN, ANY, ALL, EXISTS, and NOT EXISTS.

Chapter 18: Set Operations (UNION, INTERSECT, EXCEPT)

Horizontal Joins vs Vertical Set Operations, UNION vs UNION ALL performance, INTERSECT, EXCEPT and MINUS, and mandatory compatibility rules.

Chapter 19: CASE Expressions

Searched CASE vs Simple CASE syntax, value categorization, conditional aggregation pivoting, divide by zero guards, custom ORDER BY sorting, and bulk conditional updates.

Chapter 20: Conditional Logic and Portability

Comparing ANSI SQL standards (CASE, COALESCE, NULLIF) against vendor specific shortcuts (IF, IFNULL, NVL, ISNULL) for cross database portability.

Chapter 21: Common Table Expressions (CTEs and Recursive CTEs)

WITH clause syntax, chaining multiple CTEs, CTE with JOINs and aggregations, WITH RECURSIVE for organizational hierarchies, and CTE vs Subquery comparison.

Chapter 22: Window Functions (Ranking, Value and Distribution)

OVER (PARTITION BY ... ORDER BY ...), ROW_NUMBER(), RANK(), DENSE_RANK(), LAG(), LEAD(), FIRST_VALUE(), LAST_VALUE(), NTILE(), PERCENT_RANK(), and CUME_DIST().

Chapter 23: Advanced Aggregation and Running Totals

Conditional aggregation pivoting, cumulative running totals with UNBOUNDED PRECEDING, rolling 7 day moving averages, group extremes, and percentage share calculations.

Database Architecture, Optimization and Design

Chapter 24: Views (Simple, Complex and Updatable)

CREATE VIEW, CREATE OR REPLACE VIEW, hiding sensitive columns, simplifying multi table joins, and WITH CHECK OPTION for updatable views.

Chapter 25: Indexes and Cardinality

B+ Tree internals, Clustered Primary Indexes, Unique, Composite (Leftmost Prefix Rule), Covering, Prefix, and Full Text indexes, plus Cardinality and Selectivity formulas.

Chapter 26: Query Optimization and Execution Plans

Parser to Storage Engine pipeline, EXPLAIN vs EXPLAIN ANALYZE telemetry, Access Paths, Physical Join Algorithms, SARGability rules, and Keyset Pagination.

Chapter 27: Transactions and ACID Architecture

Atomicity, Consistency, Isolation, and Durability (Undo and Redo Logs), START TRANSACTION, COMMIT, ROLLBACK, and production Node.js mysql2 transaction pooling.

Chapter 28: Transaction Isolation Levels and Concurrency

Dirty Read, Non Repeatable Read, Phantom Read, Read Uncommitted, Read Committed, Repeatable Read, Serializable, Shared and Exclusive Locks, MVCC, and Deadlock resolution.

Chapter 29: Database Normalization (1NF to 5NF and BCNF)

Functional dependencies, Insertion, Update, and Deletion anomalies, step by step 1NF, 2NF, 3NF, BCNF, 4NF, 5NF, and strategic Denormalization trade offs.

Chapter 30: Database Relationships

Complete SQL DDL schemas and query patterns for One to One (1:1), One to Many (1:N), and Many to Many (M:N) using Junction and Bridge tables.

Chapter 31: ER Diagrams

Chen and Crow's Foot notations, Strong and Weak entities, Key, Multivalued, and Derived attributes, Cardinality, Optionality, and converting ER models into SQL DDL.

Part 05 • Chapters 32 to 38

Procedural SQL, Security and Administration

Chapter 32: Stored Procedures

DELIMITER rules, IN, OUT, and INOUT parameters, DECLARE variables, IF ELSE, WHILE, REPEAT, and LOOP controls, Cursors, and SQLEXCEPTION error handlers.

Chapter 33: User Defined Functions (UDF)

CREATE FUNCTION with RETURNS and DETERMINISTIC characteristics, building reusable discount and tax calculators, and UDFs vs Stored Procedures.

Chapter 34: Triggers

BEFORE and AFTER INSERT, UPDATE, and DELETE triggers, NEW and OLD row references, salary audit trails, stock syncing, record archiving, and production pitfalls.

Chapter 35: Security

User provisioning with host restrictions, GRANT and REVOKE privileges, Role Based Access Control (RBAC), SSL/TLS hardening, and SQL Injection attack and defense.

Chapter 36: Prepared Statements

Two step PREPARE and EXECUTE lifecycle, native SQL syntax, PHP PDO and MySQLi parameter binding, Python MySQL and psycopg2 drivers, and allowlist sorting.

Chapter 37: Database Backup and Recovery

Logical backups (mysqldump, pg_dump), Physical binary backups, Point in Time Recovery (PITR) with binary logs and WAL, and disaster recovery workflows.

Chapter 38: Advanced Database Concepts

Database Administration (DBA) tuning, Table Partitioning, Horizontal Sharding, Master Replica Replication, Vertical vs Horizontal Scaling, and CAP Theorem.

Part 06 • Chapters 39 to 45

Modern SQL, Backend Integration and Real World Projects

Chapter 39: JSON in SQL

Native JSON and JSONB storage, JSON_EXTRACT(), path operators, indexing generated columns, and Relational vs JSON hybrid modeling.

Chapter 40: Regular Expressions

Full Text Search with MATCH() AGAINST() alongside REGEXP, RLIKE, REGEXP_LIKE(), REGEXP_SUBSTR(), and REGEXP_REPLACE() for pattern validation and cleaning.

Chapter 41: Advanced SQL Patterns

Data deduplication, Top N per group, Nth highest salary, Gaps and Islands, Month over Month growth, Cohort retention, and 35 solved practical lab and interview questions.

Chapter 42: SQL with Backend Development
